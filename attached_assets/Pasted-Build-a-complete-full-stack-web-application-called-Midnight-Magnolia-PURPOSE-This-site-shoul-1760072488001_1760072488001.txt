Build a complete full-stack web application called “Midnight Magnolia.”

🎯 PURPOSE:
This site should reflect a dual-platform architecture:
- Vercel hosts the public eCommerce and AI experience for visitors.
- Replit powers the private creator dashboard, admin tools, and backend automations.

🌙 BRANDING:
Use the following brand colors and fonts:
- Midnight Blue: #0A192F (background)
- Magnolia White: #FAF3E0 (text)
- Rich Gold: #D4AF37 (accents)
- Sage Green: #A3B18A (secondary)
Typography:
- Headers: Playfair Display
- Body: Lora
- Accents: Montserrat
Theme: Southern Gothic elegance with calm, modern flow.

🏗️ STACK:
Next.js + TypeScript
Supabase for authentication and storage
OpenAI API for journal + prompt generation
Stripe for paid memberships
Notion API integration (optional)
Deploy on Replit Autoscale or Reserved VM

📁 FOLDER STRUCTURE:
/src
 ├── index.tsx              → Public landing page
 ├── /about                 → Brand mission + story
 ├── /shop                  → Product showcase (tarot, journals, art)
 ├── /tiers                 → Membership pricing + Stripe integration
 ├── /signup                → Creator/Member registration
 ├── /dashboard             → Auth-protected creator hub
 ├── /api                   → AI + automation endpoints
 └── /components             → Reusable UI components (cards, nav, footer)

🌐 DOMAIN ROUTING:
- midnight-magnolia.com → Vercel (public)
- creator.midnight-magnolia.com → Replit (private)

🔐 ENVIRONMENT VARIABLES:
OPENAI_API_KEY=sk-...
SUPABASE_URL=https://...
SUPABASE_ANON_KEY=...
STRIPE_SECRET_KEY=sk_live_...
NOTION_API_KEY=secret_...

💫 CORE FEATURES:
1. Public landing page showcasing the Midnight Magnolia brand, products, and story.
2. Authenticated creator dashboard on `/dashboard` for internal content, journal generation, and AI automations.
3. API endpoints:
   - `/api/create-journal` → Generate reflective writing using OpenAI.
   - `/api/affirmation` → Generate affirmations for healing or creativity.
   - `/api/upload-content` → Save entries to Supabase or Notion.
4. Stripe-powered tier system under `/tiers` for memberships.
5. Elegant responsive design with gold hover effects, magnolia and crescent moon iconography.
6. Secure `fetch` link between Vercel (public) and Replit (private) using a shared secret header.

- Footer: Social links, © Midnight Magnolia, Rumi-Nations LLC
