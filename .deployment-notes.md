# Deployment Configuration

## Application Architecture

This is an **Express + Vite** application, NOT a Next.js application.

### Stack:
- **Backend**: Express.js server (server/index.ts)
- **Frontend**: React + Vite (client/)
- **Build**: Vite for client, esbuild for server

### Running the App:

```bash
# Development
npm run dev

# Production
npm run build
npm start
```

### Deployment:

This app should be deployed as a **Node.js application**, not to Vercel or other Next.js platforms.

The server listens on the PORT environment variable (default: 3000).

### Disabled Files:

The following files have been disabled as they were causing confusion:
- `next.config.mjs.disabled` - Not needed (this is not a Next.js app)
- `middleware.ts.disabled` - Not needed (this is not a Next.js app)
- `app/` directory - Contains unused Next.js pages (actual app is in `client/`)

### Important:

**DO NOT** enable Next.js configuration or try to deploy to Vercel. This is a traditional Express server application.
